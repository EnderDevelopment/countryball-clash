# Countryball Clash — Open Source Browser Strategy Game

Countryball Clash is an open source project and turn-based browser strategy game about controlling a fictional campaign map, managing troops and supplies, attacking neighboring territories, fortifying positions, and expanding the Atlantic Union across an alternate-history conflict.

## Install

1. Clone or download the repository.
2. Keep `index.html`, `game.js`, and `styles.css` in the same directory.
3. Open `index.html` in a modern web browser.
4. Enable JavaScript if the browser asks for permission.

No build process, server, database, or package installation is required.

## Use

1. Select one of the Atlantic Union territories on the campaign map.
2. Click “Deploy 2 troops” to spend 2 supplies and add troops to the selected territory.
3. Click “Fortify +3” to spend 3 supplies and increase the selected territory’s fortification level.
4. Select an adjacent rival territory to launch an attack from the selected Atlantic Union territory.
5. Alternatively, use “Attack neighbor” to automatically attack the weakest available neighboring rival territory.
6. Click “End turn” to receive supplies, update industry, reset available actions, and let the Iron Pact and Neutral states take their turns.
7. Capture territories and reach control of 10 regions to win.
8. The campaign ends in defeat if the Atlantic Union loses all territories, or ends after turn 30.
9. Click “New campaign” to reload the game and restart.
